# explore

A data-first window onto regional industrial ecosystems: how many actors exist in a geography, sector or subsector, who they are, and what characterises them.

- **Linear:** Explore.
- **Data:** shows **only approved exports** produced by the research pipeline. This repository contains no personal data, no contact details and no unreviewed records. It never writes back to the source.
- **Relation to the main site:** may be served as a subsite of the main website.
- **Cloud agents:** `.cursor/environment.json` runs `scripts/cloud-install.sh` / `scripts/cloud-start.sh` (environment E2, web).
